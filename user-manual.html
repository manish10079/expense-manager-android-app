Quick start — your first 5 minutes

A short path from a fresh install to a useful dashboard.

  1. Walk through onboarding. Swipe (or tap NEXT) through the intro pages, then choose Continue with Google, sign up with email, or tap Continue as Guest to stay fully offline.
  2. Set up your profile. Enter your name, gender and date of birth so the dashboard greeting and insights are personalised.
  3. Pick your currency. Go to Settings → App Preferences → Currency and search for your country.
  4. Log your first expense. Tap the + at the centre of the bottom bar, type the amount on the keypad, pick a category, then press Add.
  5. Set one budget. Open Plans → Budgets → ADD A BUDGET, choose the categories to cap and set a monthly limit.
  6. Turn on your safety net. In Settings → Security & Privacy, enable App Lock and set a 4-digit PIN.
  7. Protect your history. In Data Management, enable Auto Backup and (if signed in) Cloud Sync.
Good to know

The app is offline-first. Everything works without an account — signing in only adds cloud sync, cross-device restore and the ability to earn or redeem Pro passes.

App Lock (PIN)

The lock screen you meet each time you open the app once App Lock is enabled.

SecurityFree

What this screen does

Guards your financial data behind a 4-digit PIN, optionally backed by your device's fingerprint or face unlock. The same screen is used to create a PIN the first time and to unlock afterwards, and it doubles as the recovery flow if you forget the PIN.

What's on the screen

ElementWhat it doesHow to use it
“Welcome Back” headerUnlock mode — asks for the PIN you already set Enter your 4 digits
“Create a 4-digit PIN”Setup mode, first entry Type 4 digits; the app then asks you to confirm them

How to use it

  1. Turn App Lock on in Settings → Security & Privacy.
  2. Choose a security question from the list and save an answer you will remember — this is your only self-service way back in.
  3. Enter a 4-digit PIN, then confirm it.
  4. From then on the app asks for the PIN (or your biometric) when you open it, following whatever Auto Lock Duration you chose.
Important

Your PIN is hashed and stored on the device; there is no server copy. If you forget both the PIN and the answer to your recovery question, the only route back in is reinstalling the app — which clears local data. Keep a JSON backup from Data Management if you want a safety net.

Detected Transactions

Bank, UPI and wallet messages the app parsed on-device, waiting for your confirmation before they become real transactions.

SMS importOptional

What this screen does

When SMS detection is on, incoming financial messages are read locally and turned into suggestion cards here. Nothing is added to your ledger automatically — each card waits for you to review it in the transaction editor and press Add. Non-financial messages (OTP, promo, no amount) never appear.

What's on the screen

ElementWhat it doesHow to use it
Search boxSearches by merchant, sender or message text Type any fragment to narrow the list
Filter chipsAll, Income, Expense Tap a chip to show only that kind of detection
Detection card Shows the amount, credited/debited verb, sender, the original SMS text and a suggested category Tap it to open Add Transaction pre-filled; edit if needed, then press Add
Swipe on a cardDeletes a single detection Swipe left/right, then use Undo in the snackbar if it was a mistake
Long-press / selection modeMulti-select detections for bulk work Long-press one card, then use Select all, Deselect all or Delete selected
Edit sheetQuick edit of Amount, Note and Category before adding Open a card's edit action, adjust, tap Add
Clear All PendingRemoves every outstanding detection Use when you've already logged those spends another way
Day groupingGroups cards under Today / Yesterday / datesInformational
Empty states“No detected transactions yet” / “Nothing here” for a filtered view Clears the search or filter to see everything again

How to use it

  1. Tap the bell on Home, or open a “Transaction Detected” notification.
  2. Skim the cards and tap the ones that are real spends you haven't logged.
  3. In the editor, fix the amount, category, payment method or note if the parse was off.
  4. Press Add. The card leaves the inbox and the transaction joins your ledger.
  5. Swipe away anything that isn't a real transaction.
Privacy

Detection uses RECEIVE_SMS only — no READ_SMS, no SEND_SMS. Messages are parsed on-device and SMS bodies are never uploaded. Deny the permission and the whole feature simply stays off.
