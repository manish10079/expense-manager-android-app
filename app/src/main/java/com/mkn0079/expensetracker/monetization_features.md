# Expense Tracker - Monetization Features Guide

This document lists all the features implemented in the Expense Tracker application, categorized by their monetization status (Free, Ad-Supported, or Premium).

---

## 🏠 Home Screen (Dashboard)

| Feature | Status | Description |
| :--- | :--- | :--- |
| **Total Balance View** | **FREE** | Real-time visibility of total balance across all accounts. |
| **Privacy Mode Toggle** | **FREE** | Manual toggle (Eye Icon) to hide/mask all financial amounts on the dashboard. |
| **Smart Privacy (Auto-Hide)** | **FREE** | Automatically hides financial amounts after 10 seconds of inactivity to protect your data in public. |
| **Spending Breakdown** | **FREE** | Quick overview of Today's Spending, Income, and Expense totals. |
| **Recent Activity List** | **FREE** | View the most recent transactions directly on the dashboard. |

---

## 🔎 Transactions & Search

| Feature | Status | Description |
| :--- | :--- | :--- |
| **Basic Search** | **FREE** | Search transactions by Notes (text) or specific amounts. |
| **Advanced Search Filters** | **AD-SUPPORTED** | Unlock the ability to filter results by **Category** or **Payment Method/Wallet** in both the Search Bar and the Sort & Filter Modal. |
| **Transaction Deletion** | **FREE** | Ability to delete individual or multiple transactions. |

---

## 🛡️ Security & Privacy

| Feature | Status | Description |
| :--- | :--- | :--- |
| **App Lock (PIN)** | **FREE** | Set a secure PIN to prevent unauthorized access to the app. |
| **Biometric Lock** | **FREE** | Use Fingerprint or Face ID for faster secure access. |
| **Auto-Lock (Presets)** | **FREE** | Options for "Immediately", "1 Minute", and "5 Minutes" are free for everyone. |
| **Extended Auto-Lock** | **AD-SUPPORTED** | Unlock longer durations (10, 15, 30, 45, 60 minutes) to avoid frequent PIN prompts. |
| **Custom Auto-Lock** | **AD-SUPPORTED** | Set any custom duration (e.g., 12 minutes) for app locking. |
| **Blur In Recents** | **AD-SUPPORTED** | Blurs the app preview in the "Recent Apps" switcher for extra privacy. |
| **Block Screenshots** | **AD-SUPPORTED** | Prevents screenshots and screen recordings within the app for maximum security. |

---

## 🎨 Transaction Card Customization

| Feature | Status | Description |
| :--- | :--- | :--- |
| **Amount Visibility** | **FREE** | Toggle visibility of the transaction amount on the card. |
| **Category Icon** | **FREE** | Show or hide the category icon (e.g., Food, Transport) on transaction cards. |
| **Transaction Date** | **FREE** | Show the specific date of each transaction in the list. |
| **Payment Method Label** | **AD-SUPPORTED** | Show which wallet/bank was used (e.g., Cash, Visa) directly on the card. |
| **Transaction Time** | **AD-SUPPORTED** | Display the exact time the transaction was recorded. |
| **Income/Expense Labels** | **AD-SUPPORTED** | Add clear text labels ("Income" / "Expense") to transaction cards. |
