How to read this

  • Left frame is the supplied settingscreen.html — same sections in the same order, same palette (#0B0C10 page, #151824 cards, #222738 borders, #8E9BAE secondary ink), same icon tiles, Pro badge, ACTIVE / Unlocked pills and floating nav.
  • Right frame is the same markup under .screen.light. Nothing about the layout moves: only surfaces and ink change. The accents that carry identity — the hero's violet→fuchsia→indigo edge, the avatar ring, the Pro badge, the tile colours and the FAB — stay identical in both modes, which is what the mockup's own toggle already did.
  • Each frame scrolls on its own; the header is pinned at the top of the screen and the floating nav stays put, so the list scrolls beneath both, exactly like the app.
