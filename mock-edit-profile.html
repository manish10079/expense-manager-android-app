How to read this

  • Each frame is a fixed 412 × 915 screen with the header and the Save Changes footer pinned, and the avatar block plus the five field cards sitting in the scroll region between them. With these five fields the content fits the frame — nothing scrolls until a longer value or a larger font scale pushes past it.
  • The palettes are the supplied files' own, not re-invented: dark is the Obsidian theme (#090B10 page, #131622 card, rgba(255,255,255,.08) hairline), light is the canvas theme (#F8FAFC, white cards on #E2E8F0).
  • Where the two supplied screens genuinely differ, the difference is kept and driven by the theme class rather than smoothed over — see the table below.
  • One deliberate substitution: the light screen carries a hosted photo for the avatar; the dark screen's vector illustration stands in for both so the file renders offline with no external image. The ring, sizes and inner border are per-theme as supplied.
  • The dark screen's status bar and navigation are drawn without a backdrop; both frames pin them to the screen colour here so scrolled content does not show through.
