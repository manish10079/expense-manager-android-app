What changed from the original single-palette list
  • The original used one hex value for both themes. On white cards every one of those pastels scored only 1.6–3.0:1. Each hue now has a deepened light-mode twin.
  • Brand violet #7A52FF was replaced. It scored 2.6:1 on the dark card and had no separation from the app's own purple. It is now a lighter, distinct indigo in dark and a deeper indigo in light.
  • Duplicate hues were spread apart so list rows stay distinguishable: the 3× green, 3× orange, 3× grey and 2× red repeats now use distinct red / rose / sky / blue / green / teal / lime / yellow / amber / orange / deep-orange / brown.
  • Icon names were aligned to ExpenseTrackerIconRegistry.kt so the file describes icons the app can actually draw.
